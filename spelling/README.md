# Silabex Spelling

The goal Silabex is to be a sutible writing system for the english language.
While the writing system takes phonetic spelling as it's base, adhearing to phonetic spelling too closely is a bad idea in my opinion.
The benefits of a standard spelling system far outweighs the benefits of a strict phonetic spelling system.
The writing system should also preferentialy represent common english sounds using shapes that are simple to both read and write.
More complex shapes can then be reserved for less common symbols.

The goal of this project is to build a standard spelling system for Silabex.
Analyzing english text to identify common sylable construction to ensure the writting system can effectivly represent the english language.
